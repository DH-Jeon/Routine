# 루틴 시간표

24시간 원형 생활계획표와 할 일 목록을 한 화면에서 관리하는 모바일 웹앱입니다.
외부 라이브러리 없이 **순수 HTML/CSS/JavaScript** 단일 파일(`index.html`)로 동작합니다.

👉 **접속:** https://dh-jeon.github.io/Routine/

## 기능

- **24시간 원형 시간표** — 0시(자정)가 맨 위, 시계방향으로 24칸(칸당 1시간)
  - 칸을 탭하면 하단 시트에서 활동 이름 입력 + 파스텔 색상 선택
  - 같은 활동을 연속 시간에 넣으면 구분선 없이 하나로 이어 표시
  - 활동을 비우면 기본 회색으로 복귀
- **할 일 목록**
  - 상단 고정(sticky) "+ 할 일 추가" 버튼으로 입력
  - 체크 동그라미 탭으로 완료(취소선 + 흐리게) 처리
  - 항목을 왼쪽으로 스와이프하면 삭제 (터치·마우스 모두 지원)
- **자동 저장** — 모든 변경이 `localStorage`에 저장되어 새로고침해도 유지
- **다크모드** — 시스템 설정(`prefers-color-scheme`)에 따라 자동 전환
- **반응형** — 세로 화면은 위/아래, 가로 화면은 좌/우 분할. 확대·회전에도 레이아웃 유지

## 사용법

`index.html`을 브라우저에서 열기만 하면 됩니다. 빌드나 설치 과정이 없습니다.

```bash
# 로컬에서 바로 열기
open index.html

# 또는 간단한 로컬 서버로
python3 -m http.server
```

## 기술

- HTML / CSS / JavaScript (의존성 없음)
- 시간표는 SVG로 렌더링
- 데이터는 `localStorage`에 저장
  - `routine.schedule` — 시간표 24칸 배열
  - `routine.todos` — 할 일 목록

## 데이터 구조

```js
// 시간표: 0~23시
schedule = [{ hour: 0, label: '', color: '#eeeeee' }, ... ]

// 할 일
todos = [{ id: 1, text: '운동하기', done: false }, ... ]
```
